# SunnyWeather
✨ 功能介绍
- 🌍 根据定位获取当前城市天气
- 🔎 支持城市搜索功能
- ☀️ 展示实时天气（温度、湿度、风速、天气状况等）
- 📅 查看未来几天的天气趋势
- 🌓 根据天气自动切换背景风格（日/夜）
- 🔁 下拉刷新最新天气数据
- 🌐 使用第三方天气 API 接口（如和风天气、OpenWeatherMap）


🧑‍💻 技术栈
- Java / Kotlin
- Android Studio
- Retrofit2 + OKHttp
- Gson / Moshi 解析 JSON
- ViewModel + LiveData
- 高德 / 百度 / 系统定位服务
- Glide 图片加载
